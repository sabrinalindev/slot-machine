# Slot Machine

This project simulates a classic slot machine experience with 3 reels, each containing 5 possible symbols. 
Users can place a bet, spin the reels, and try to land a jackpot by matching all three reels.

### How it is made:
#### Tech Used:HTML,CSS and JavaScript


## Getting Started

1. Clone this repository
```bash
   git clone https://github.com/sabrinalindev/slot-machine.git
```
2. Open `index.html` in your browser

## How to Play

1. Enter the amount you'd like to bet
2. Click the "Spin" button
3. Each of the 3 reels will randomly land on one of 5 symbols:

   ❤️ 🍒 🍋 🍊 🍇

4. If all 3 reels match the same symbols, JACKPOT!!

## Features

- 3 reels × 5 unique symbols (❤️ 🍒 🍋 🍊 🍇)
- Randomized spin outcomes
- Jackpot detection when all 3 reels match
- Responsive design

### Why this stack is chosen:

- **JavaScript**:
  — keeps the codebase lightweight and easy to understand.
